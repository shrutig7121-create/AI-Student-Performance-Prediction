# AI-Powered Student Performance Prediction System

## Project Overview
A beginner machine learning project that analyzes student data and predicts final marks using Python and Linear Regression.

## Objectives
- Explore relationships between study hours, attendance, previous scores, and final marks.
- Visualize patterns using charts and a correlation heatmap.
- Train and evaluate a Linear Regression model.
- Predict marks for a new student's inputs.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Model Evaluation
- **Mean Absolute Error (MAE):** 5.43 marks
- **R² Score:** 0.757

These metrics were obtained using a held-out test set from a simulated dataset.

## Project Files
- `AI_Student_Performance_System.ipynb` — analysis, visualizations, and machine learning workflow.
- `student_performance_data.csv` — simulated student performance data.

## Limitations
The dataset was generated synthetically for learning purposes. The reported metrics do not establish performance on real student data.
